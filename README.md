# Curso Front-End - Rafael Ferreira 

## Descrição
Este repositório contém projetos desenvolvidos durante o curso de FrontEnd, utilizando tecnologias como HTML, CSS, JavaScript, Bootstrap e jQuery.

## Tecnologias Utilizadas
- **HTML**: Estrutura das páginas
- **CSS**: Estilização (via Bootstrap)
- **JavaScript**: Interatividade
- **Bootstrap**: Framework CSS para design responsivo
- **jQuery**: Biblioteca JavaScript para manipulação DOM

## Estrutura do Projeto
```
CursoFrontEnd_Projetos/
├── README.md
├── Projetos/
│   ├── Cadastro.html
│   ├── Exemplo_Tabela.html
│   └── SistemaCorporativo.html
└── resources/
    ├── css/
    │   └── bootstrap.min.css
    ├── fonts/
    └── js/
        ├── bootstrap.min.js
        └── jquery.min.js
```

## Projetos Incluídos
1. **Cadastro.html**: Página de cadastro de usuários
2. **Exemplo_Tabela.html**: Exemplo de tabela com dados
3. **SistemaCorporativo.html**: Sistema corporativo básico

## Como Executar
Para visualizar os projetos, abra os arquivos HTML diretamente no navegador. Certifique-se de que a estrutura de pastas seja mantida para que os recursos (CSS e JS) sejam carregados corretamente.
